**Python · Streamlit · TensorFlow/Keras · Pandas**

A machine-learning web application that allows users to upload an image of a traffic sign and receive a predicted classification from a trained Keras model.

The project demonstrates how a trained machine-learning model can be connected to an interactive web interface and prepared for deployment.

**Key engineering areas:**

* Machine-learning model integration
* Image upload and preprocessing
* Classification and label mapping
* Streamlit interface development
* Python dependency management
* Cloud application deployment

[View Repository](https://github.com/Al-Farhan-Seg/traffic-sign-recognition-app) · [Live Application](https://ml-group-3-traffic-sign-recogniser.streamlit.app/)

### SACCO Management System

**Python · Object-Oriented Programming**

A modular academic software system modelling the core operations of a Savings and Credit Cooperative Organisation.

The application represents members, staff, accounts, savings, loans, payments, and withdrawals using separate Python modules and object-oriented design.

**Concepts demonstrated:**

* Classes and objects
* Inheritance and method overriding
* Encapsulation
* Object composition
* Modular software design
* Separation of responsibilities
* Translation of business requirements into software entities
